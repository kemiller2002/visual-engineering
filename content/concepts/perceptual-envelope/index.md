# Perceptual Envelope

A **Perceptual Envelope** is the bounded set of visual parameter combinations under which a specified observer can perform a specified task within prespecified accuracy, comprehension, time, effort, and error-cost limits under specified environmental conditions.

It is not a medical diagnosis and it is not a named accessibility mode.

## Variables

Candidate dimensions include:

- font size and x-height;
- weight and width;
- optical size;
- letter, word, and line spacing;
- line length;
- polarity;
- luminance and contrast;
- categorical color separation;
- density;
- motion;
- device and environmental conditions.

## Engineering implication

Prefer strong universal defaults and direct user control first. Use adaptive presentation only where evidence shows that a stable, useful profile can be recovered without changing semantics or imposing excessive calibration burden.
