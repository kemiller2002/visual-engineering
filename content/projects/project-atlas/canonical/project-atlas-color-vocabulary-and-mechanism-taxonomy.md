# Project Atlas - Color Vocabulary and Mechanism Taxonomy

## Purpose

Establish a controlled vocabulary so every Atlas document uses the same meanings for color-related terms.

1. Physical variables
2. Perceptual variables
3. Cognitive mechanisms
4. Communication functions
5. Measurement methods

## Working Definitions

### Accent

An element whose perceptual distinctiveness is sufficient to reliably attract attention for the current task.

### Hierarchy

The ordered probability that observers attend to elements.

### Harmony

A subjective judgment emerging from multiple interacting variables rather than hue geometry alone.

### Palette

A constrained system of interacting colors, not independent swatches.
